# Noir Brew ☕🤖

Noir Brew is a React-based automated AI cafe website concept where users can explore a smart menu, personalize orders, and interact with an AI assistant for quick recommendations.

## Overview

This project is designed as a modern cafe experience powered by AI.  
It combines a clean React frontend with automated customer interactions such as:

- AI-powered drink and food recommendations
- Personalized order flow based on user preferences
- Smooth, responsive user interface for desktop and mobile
- Fast ordering experience with smart suggestions

## Tech Stack

- **React** for the user interface
- **JavaScript** for application logic
- **CSS** for styling and responsive design

## Planned Features

- Dynamic cafe menu with categories
- AI chat assistant for menu discovery
- Smart combo suggestions (drink + snack pairings)
- Order summary and checkout-friendly flow
- User profile preferences for tailored suggestions

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/tilak28/noir-brew.git
   ```
2. Move into the project directory:
   ```bash
   cd noir-brew
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```

## Vision

Noir Brew aims to blend cafe culture with automation and AI, creating a friendly digital storefront where users can discover, customize, and order with confidence.
